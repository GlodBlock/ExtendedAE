# ME Oversize Interface

<Row gap="20">
<BlockImage id="extendedae:oversize_interface" scale="8"></BlockImage>
<GameScene zoom="8" background="transparent">
  <ImportStructure src="../structure/cable_oversize_interface.snbt"></ImportStructure>
</GameScene>
</Row>

The ME Oversize Interface has the same number of slots as an <ItemLink id="extendedae:ex_interface" />, but each slot can hold 16 times as many
items by default (configurable). This means it can hold 1024 (64 x 16) items per slot.

Specific multipliers can be configured for certain content from other mods.
