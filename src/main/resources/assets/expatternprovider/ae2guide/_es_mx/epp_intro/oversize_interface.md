# Interfaz ME sobredimensionada

<Row gap="20">
<BlockImage id="expatternprovider:oversize_interface" scale="8"></BlockImage>

La interfaz ME sobredimensionada tiene el mismo número de ranuras que la <ItemLink id="expatternprovider:ex_interface" />, pero puede contener x16 veces (configurable) más
objetos por ranura. Esto significa que puede contener 1024 (64x16) objetos por ranura.
