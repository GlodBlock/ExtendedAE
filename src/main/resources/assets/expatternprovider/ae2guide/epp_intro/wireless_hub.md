# ME Wireless Hub

<Row gap="20">
<BlockImage id="expatternprovider:wireless_hub" scale="6"></BlockImage>
</Row>

The ME Wireless Hub works exactly like <ItemLink id="expatternprovider:wireless_connect" />, but it can connect up to 8 hubs/connectors
at the same time.

## Connection Configuration

There are 8 ports on the ME Wireless Hub. It automatically finds an available port when you link it with <ItemLink id="expatternprovider:wireless_tool" />.

However, when all of its ports are occupied, you need to disconnect one manually by clicking the 'X' button before setting up new connections.
